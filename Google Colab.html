Overview

摘要與核心重點

摘要

更新日期：2026-09-29　發布日期：2026-09-29

Google Colab 是 Google 提供的雲端 Python 筆記本：你在瀏覽器裡寫程式，程式實際跑在 Google 的機器上，所以不用在自己的電腦裝環境，也能借用 GPU。免費版可使用 T4 GPU，但資源有配額，官方說明「不保證、也不無限」。付費方案以 compute units（運算額度）計算：官方定價頁列出 Colab Pro 每月 US$10.49 含 100 單位、Colab Pro+ 每月 US$52.49 含 600 單位、Pay As You Go 100 單位 US$10.49，並註明額度 90 天後到期。訂閱 Google AI 方案也會附 Colab 額度，且與 Colab 自己的額度加進同一個餘額：Google 方案頁明列 Ultra 為每月 1,000 單位，Pro 沒有官方數字，作者的 Google AI Pro 帳號實測顯示 200 單位。新手最常踩的三個坑是：執行階段是暫時的、套件每次都要重裝、用完沒有結束執行階段。若下文與此摘要衝突，以此摘要為準。

What is it

Colab 是什麼

Colab（Colaboratory）是一個放在瀏覽器裡的 Python 工作台，跑在 Google 的機器上。你的電腦只負責顯示畫面和接收鍵盤輸入，真正執行程式的是 Google 機房裡分配給你的那台虛擬機。

比較項目在自己電腦上跑在 Colab 上跑
程式在哪執行你的電腦Google 分配的虛擬機
要不要先裝環境要不用，開瀏覽器即可
GPU看你有沒有顯卡可選 GPU，實際拿到哪一種「視可用性而定」
執行環境是否持久是否，是暫時的（見下方「三個常見的坑」）

最常見的用途是借 GPU 來訓練或微調小型模型，其次是學 Python、做資料分析，以及分享可以直接執行的範例。

Notebook

Notebook 與儲存格是什麼

Notebook（筆記本）是一種文件格式，副檔名 .ipynb。它把「說明文字」和「可以執行的程式碼」放在同一份文件裡，切成一個個儲存格（cell）：

  • 文字儲存格：寫說明，像一般筆記。
  • 程式碼儲存格：寫 Python，執行後結果直接顯示在這一格下面，包含文字、表格與圖表。

可以把它想成實驗紀錄本：每一頁先寫「這次想做什麼」，接著是實驗步驟，結果貼在旁邊。你可以只重做其中一頁，不必整本重來。

比較項目一般 .py 腳本Notebook
執行方式整個檔案從頭跑到尾一格一格分開跑
中間結果要自己印出來或寫檔每一格的結果留在畫面上
適合寫成品、上線的服務實驗、試錯、教學、展示

一格一格跑的好處在訓練模型時特別明顯：載入資料很花時間，只要跑一次，之後調參數就反覆重跑後面幾格，不必每次重新載入。

Quickstart

三分鐘上手

介面語言不同，選單名稱會跟著變。以下用英文介面的名稱，這些名稱都取自 Colab 官方 FAQ 與官方說明筆記本。

  1. 登入並新增筆記本。用 Google 帳號登入 colab.research.google.com，新增一個筆記本。
  2. 跑第一格。在第一個程式碼儲存格輸入 print("hello")，按 Shift+Enter 執行，結果會顯示在這格下面。
  3. 選 GPU。從選單 Runtime > Change runtime type 選擇硬體加速器。官方說明付費方案可以選更快的 GPU 與更多記憶體，「視可用性而定」。免費版提供 T4 GPU，有配額限制。
  4. 確認拿到哪一張卡。執行下面的第二格程式碼。它會呼叫 nvidia-smi，沒有 GPU 時會印出 Not connected to a GPU。
  5. 用完就結束。從選單 Runtime > Disconnect and delete runtime 結束執行階段，官方 FAQ 說這會讓分配給你的虛擬機回到原始狀態。
colab-first-cells（Notebook 儲存格，不是一支 .py） 
# 儲存格 1：確認環境正常
print("hello")

# 儲存格 2：確認有沒有拿到 GPU（取自 Colab 官方說明筆記本）
gpu_info = !nvidia-smi
gpu_info = '\n'.join(gpu_info)
if gpu_info.find('failed') >= 0:
  print('Not connected to a GPU')
else:
  print(gpu_info)

# 儲存格 3：安裝需要的套件（每個新的執行階段都要重跑）
!pip install 套件名稱

# 儲存格 4：掛載 Google 雲端硬碟，把要保留的結果存進去
from google.colab import drive
drive.mount('/content/drive')

程式碼前面的驚嘆號 ! 代表「這一行交給 shell 執行」，不是 Python 語法。

資源不保證

Colab 官方 FAQ 的原文是：「Colab resources are not guaranteed and not unlimited, and usage limits sometimes fluctuate.」而且可用的 GPU 與 TPU 種類「會隨時間改變」。你可能在某個時段拿不到想要的 GPU，這不是設定錯誤。（來源：Colab FAQ，更新 2026-09-29）

Compute Units

額度怎麼算

免費版不用額度，但有配額，用超過就會被限制。付費方案改用 compute units（運算額度）：開著執行階段、用越強的硬體，扣得越快。

官方定價頁列出的方案（2026-09-29）

方案價格額度其他
Pay As You Go 100 單位 US$10.49
500 單位 US$52.49		 買多少有多少 不用訂閱；額度 90 天後到期
Colab Pro US$10.49／月 每月 100 單位 更快的 GPU、更多記憶體
Colab Pro+ US$52.49／月 每月 600 單位（含 Pro 的 100 單位，另加 500 單位） 額度 90 天後到期；背景執行，關掉瀏覽器也能繼續跑，最長 24 小時
Colab Enterprise 用多少付多少 — 與 Google Cloud 服務整合（BigQuery、Vertex AI）

額度用完時，官方 FAQ 的說法是：付費使用者的額度餘額耗盡後，會「回到免費版的政策與限制，直到餘額補上為止」。來源：colab.research.google.com/signup、Colab FAQ（更新 2026-09-29）。

每小時扣多少？官方沒有公開表格

官方 FAQ 沒有列出各種 GPU 每小時扣幾單位。Colab 內的資源面板（Resources）會顯示目前的使用速率（Usage rate）與剩餘額度，這是最準的數字。下方是作者的畫面：

2024 年前後的第三方實測曾整理出約略數字：T4 約每小時 1.76 至 1.96 單位，A100 約 13 至 15 單位。這些是舊的第三方資料，Colab 會調整速率，僅供估算量級，實際請以面板上的 Usage rate 為準。

訂閱 Google AI 方案也會附 Colab 額度

  • Colab FAQ 說明，Google AI 方案的 compute units 與 Colab Pro 等訂閱的額度「加進同一個餘額」，入帳時間不同。
  • Google One 方案頁（one.google.com/ai）展開權益後，Google AI Ultra 的 Colab 一項寫「每月 1,000 compute units」，並含進階加速器、背景執行與更長的執行時間。
  • Google AI Pro（台灣售價每月 NT$650）：Google 的方案頁沒有公布 Colab 額度數字，台灣公開的方案比較表也沒有 Colab 這一列。作者的 Google AI Pro 帳號在 Colab 面板看到 200 單位，也就是圖中的數字。

尚未確認的部分

Pro 方案的 200 單位只是作者單一帳號的觀察，不是 Google 公布的規格。是否每月重置、沒用完是否累積、是否適用官方定價頁上的「90 天到期」，Google 的方案頁與 FAQ 都沒有說明。想知道自己的情況，最直接的辦法是隔月同一天再看一次面板上的 Available。

Pitfalls

三個常見的坑

1. 執行階段是暫時的

筆記本檔案本身存在 Google 雲端硬碟（官方 FAQ：「Colab notebooks are stored in Google Drive」），但執行階段裡的環境不是。官方 FAQ 說 Disconnect and delete runtime 會讓虛擬機回到原始狀態，執行階段閒置太久或超過時間上限被回收時，裡面的檔案與已安裝的套件也就跟著消失。

要保留的結果，用上面第四格掛載雲端硬碟後存進去，或直接下載。

2. 套件每次都要重裝

新的執行階段是乾淨的，上一次 !pip install 裝的東西不會保留。習慣做法是把安裝指令集中放在筆記本最前面的一格，每次開新的執行階段先跑一次。

3. 用完沒有結束執行階段

官方 FAQ 說閒置的執行階段會逾時，免費版單次最長約 12 小時（「視可用性與使用狀況而定」），Pro+ 額度足夠時最長可連續執行 24 小時。但官方沒有明寫：閒置的 GPU 執行階段在逾時前，額度是否照扣。GitHub 上也有使用者回報過額度在沒有執行階段時仍被扣（colabtools #3617），該問題被當作異常回報，不能視為規格。

保險的做法是：用完就從選單手動 Disconnect and delete runtime，再看面板上的 active sessions 是不是 0。

Use Cases

可以拿來做什麼

以下項目取自 Colab 官方說明筆記本（Making the Most of your Colab Subscription）列出的範例與功能，2026-09-29 讀取。

學 Python 與資料分析

官方範例包含 pandas DataFrame 入門，以及用 RAPIDS cuDF、cuML 加速資料處理。

訓練小型模型

官方範例包含用 Flax 訓練手寫數字辨識 CNN、用 JAX 訓練 Vision Transformer，以及訓練 miniGPT 語言模型。

微調現成模型

官方範例包含用 LoRA／QLoRA 微調 Gemma，以及用 Tunix 微調 LLM。

不用 API 金鑰試 LLM

官方說明，付費方案使用者可透過 google-colab-ai 函式庫直接呼叫主流 LLM，不必自備 API 金鑰。

在 VS Code 裡用 Colab

Colab 有官方的 VS Code 擴充功能，可以在本機編輯 .ipynb，選擇 Colab 的執行階段當核心。

分享可直接執行的範例

筆記本存在 Google 雲端硬碟，也可以從 GitHub 載入，對方打開就能跑。

不適合的用途：需要長期不間斷運作的服務。執行階段有時間上限（免費版最長約 12 小時）、環境是暫時的，長時間服務應該放在自己的伺服器或雲端主機。

FAQ

常見問題（更新日期：2026-09-29）

Google Colab 是免費的嗎？怎麼收費？

可以免費使用，但有配額。免費版可使用 T4 GPU，資源不保證也不無限。需要更多資源可購買 compute units：Colab Pro 為 US$10.49／月（100 單位），Colab Pro+ 為 US$52.49／月（600 單位），Pay As You Go 為 100 單位 US$10.49 或 500 單位 US$52.49，官方註明額度 90 天後到期。來源：colab.research.google.com/signup、Colab FAQ（更新 2026-09-29）。

Google Colab 怎麼開始用？

用 Google 帳號登入 colab.research.google.com，新增筆記本，在第一格輸入 print("hello") 後按 Shift+Enter。需要 GPU 時從 Runtime > Change runtime type 選擇，用完從 Runtime > Disconnect and delete runtime 結束。完整步驟見本文「三分鐘上手」。來源：Colab FAQ（更新 2026-09-29）。

訂閱 Google AI 方案會附 Colab 額度嗎？

會。Google AI 方案的 Colab 額度與 Colab 自己訂閱的額度加進同一個餘額。Google One 方案頁明列 Google AI Ultra 為每月 1,000 compute units；Google AI Pro 沒有官方數字，作者的 Pro 帳號實測顯示 200 單位，是否每月重置與是否適用 90 天到期尚未確認。來源：one.google.com/ai、Colab FAQ（更新 2026-09-29）。

Colab 上的檔案和安裝的套件關掉之後還在嗎？

不會保留在執行階段裡。官方 FAQ 說明 Runtime > Disconnect and delete runtime 會讓分配給你的虛擬機回到原始狀態。筆記本檔案本身存在 Google 雲端硬碟，但執行階段內產生的檔案與安裝的套件需要另外存到雲端硬碟或下載。來源：Colab FAQ（更新 2026-09-29）。

上傳到 Colab 的資料或筆記本會被拿去訓練模型嗎？

查不到明文答案。Colab 的補充服務條款沒有提到使用者內容是否用於訓練模型，資料處理適用 Google 隱私權政策。因此不建議把機敏資料放進 Colab，除非已另行確認貴組織的合約與帳號類型所適用的資料政策。來源：Colab 補充服務條款（更新 2026-09-29）。

Conclusion

結論

Colab 的價值在於把「環境」這件事拿掉：打開瀏覽器就能寫 Python、借 GPU，做學習、資料處理和小型模型實驗很方便。使用時要記得三件事：環境是暫時的、套件要重裝、用完要結束執行階段。

  • 先在免費版熟悉流程，再決定要不要買額度
  • 重要結果存進雲端硬碟或下載，不要留在執行階段
  • 額度以面板上的 Available 與 Usage rate 為準，不要只看文章裡的舊數字
  • 訂閱 Google AI 方案的人，先打開 Colab 看看面板，也許已經有額度可以用

更新資訊：2026-09-29 首次發布。定價、額度與規則可能調整，以官方頁面為準。
